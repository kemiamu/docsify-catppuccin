# Catppuccin for docsify

A [Catppuccin](https://catppuccin.com/palette) colour scheme for [docsify](https://docsify.js.org) v5, in Latte and Mocha.

It is **not a theme**: it only sets CSS variables read by docsify's own core styles, so layout and decoration are left alone. Pair it with any docsify theme. The brand accent is `--theme-color`.

Demo: <https://kemiamu.github.io/docsify-catppuccin/>

## Usage

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/docsify@5/dist/themes/core.min.css">
<link rel="stylesheet" href="//kemiamu.github.io/docsify-catppuccin/latte.css" media="(prefers-color-scheme: light)">
<link rel="stylesheet" href="//kemiamu.github.io/docsify-catppuccin/mocha.css" media="(prefers-color-scheme: dark)">
```

Keep one line for a single flavour.
